# 📚 Data Structures & Algorithms in C

A collection of **Data Structures and Algorithms implementations in C**, created as part of my Computer Science coursework and DSA practice.

This repository contains implementations of fundamental data structures, written from scratch in C to understand their **logic, operations, and implementation**.

## 🧠 Topics Covered

### Stack

Implementation of a stack using arrays, including basic stack operations.

* Push
* Pop
* Display
* Stack overflow
* Stack underflow

### Queue

Implementation of a queue using arrays.

* Enqueue
* Dequeue
* Display
* Queue overflow
* Queue underflow

### Circular Queue

Implementation of a circular queue using arrays.

* Enqueue
* Dequeue
* Display
* Circular indexing
* Handling full and empty conditions

### Linked List

Implementation of a singly linked list.

* Create nodes
* Insert nodes
* Display elements
* Traverse the list
* Linked-list based operations

## 🛠️ Technologies

## ▶️ How to Run

Make sure you have a C compiler such as **GCC** installed.

### Compile

For example:

```bash
gcc stack.c -o stack
```

### Run

On Windows:

```bash
stack.exe
```

On Linux/macOS:

```bash
./stack
```

The same process can be used for the other `.c` files.
